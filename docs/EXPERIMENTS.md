## Required evidence for a completed run

- Exact source revision and command; dataset version, split and licenses.
- Model parameter count, hyperparameters, seeds, optimizer and precision.
- Accelerator type/count, training tokens, throughput, wall clock and budget.
- Loss curves, validation/test measures, evaluation protocol and error analysis.
- Checkpoints or access policy, artifacts/checksums and known limitations.

Never substitute projections or planned results for measured metrics.
